1) go to directory where app is stored
2) activate environment

.\.venv\Scripts\Activate.ps1

3) install pyinstaller

pip install pyinstaller

4) build app 

pyinstaller --noconfirm --onefile --windowed --name DroneControl droneAppHardware.py

5) locate .exe

dist\DroneControl.exe

6) icon

	find any png, jpg, preferable ico b/c then don't need to convert to .ico
	
pyinstaller --noconfirm --onefile --windowed --icon=drone_icon.ico --name DroneControl droneAppHardware.py


Note: When updating .exe start launch file, run following line in proper directory (as listed above) in termain/cmd

	py -m PyInstaller --onefile --windowed --clean --name "Drone Dashboard" droneControl4Motor.py
